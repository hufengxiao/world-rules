# Phase 21: 球类运动扩充

Phase 21 添加了 30 种球类运动规则，涵盖足球、篮球和其他球类项目。

## Phase 21-01: 足球相关规则

本阶段添加了 10 种足球相关规则，涵盖联赛、杯赛和女子足球。

### 英超联赛规则 (FootballPremierLeagueRules)

**特点**: 世界顶级联赛，商业运营完善

**基本设置**:
- 20支球队参赛
- 每队38场比赛(主客场各19场)
- 积分规则: 胜3分，平1分，负0分
- 排名规则: 积分 → 净胜球 → 总进球 → 直接对战成绩

**欧战席位**:
| 席位类型 | 数量 | 条件 |
|----------|------|------|
| 欧冠 | 4 | 前4名 |
| 欧联 | 2 | 第5名和足总杯冠军 |
| 降级 | 3 | 18-20名 |

**替补规则**:
- 现代5替补规则
- 最多3次换人机会
- 伤病换人例外

**转会规则**:
- 夏季窗口: 5-9月
- 冬季窗口: 1月
- 本土球员规则: 25人中至少8名本土培养

### 女足世界杯规则 (FootballWomenWorldCupRules)

**特点**: 2023年扩军至32队

**基本设置**:
- 32支国家队参赛
- 8个小组，每组4队
- 每组前2名及4个最佳小组第3名晋级16强
- 标准90分钟比赛

**淘汰赛规则**:
| 阶段 | 规则 |
|------|------|
| 16强 | 单场淘汰 |
| 8强 | 单场淘汰 |
| 半决赛 | 单场淘汰 |
| 决赛 | 单场决胜 |
| 三四名 | 半决赛负者对决 |

**资格获取**:
- 各洲预选赛角逐32席位
- 主办国自动参赛
- 卫冕冠军需参加预选赛

### 女子欧洲杯规则 (FootballWomenEuroRules)

**特点**: 欧洲顶级女子国家队赛事

**基本设置**:
- 16支球队参赛
- 4个小组，每组4队
- 每组前2名晋级淘汰赛
- 单场淘汰制

### 金杯赛规则 (FootballGoldCupRules)

**特点**: 北中美及加勒比地区锦标赛

**基本设置**:
- 16支球队参赛
- 4个小组，每组4队
- 邀请球队参赛(如韩国、卡塔尔等)
- 每2年举办一次

### 大洋洲国家杯规则 (FootballOceaniaCupRules)

**特点**: 大洋洲洲际锦标赛

**基本设置**:
- 8支球队参赛
- 与世界杯预选赛结合
- 冠军获世界杯资格

### 女子俱乐部世界杯规则 (FootballWomenClubWorldCupRules)

**特点**: 女子俱乐部最高荣誉

**参赛席位**:
| 洲际 | 席位 |
|------|------|
| 欧洲 | 2-3 |
| 南美 | 2 |
| 亚洲 | 2 |
| 北中美 | 1 |
| 大洋洲 | 1 |
| 非洲 | 1 |
| 主办国 | 1 |

### 南美解放者杯规则 (FootballCopaLibertadoresRules)

**特点**: 南美俱乐部最高荣誉

**基本设置**:
- 47支球队参赛(含预选赛)
- 小组赛: 8组每组4队
- 淘汰赛: 16强至决赛
- 决赛在中立场地单场决胜

### 亚冠联赛规则 (FootballAfcChampionsRules)

**特点**: 亚洲俱乐部最高荣誉

**基本设置**:
- 西亚和东亚分区
- 40支球队参赛
- 小组赛: 10组每组4队
- 淘汰赛跨区对决

### 非洲冠军联赛规则 (FootballCafChampionsRules)

**特点**: 非洲俱乐部最高荣誉

**基本设置**:
- 54支球队参赛(含预选赛)
- 小组赛: 8组每组4队
- 淘汰赛: 8强至决赛
- 冠军获超级杯资格

### 欧洲超级杯规则 (FootballUefaSuperCupRules)

**特点**: 欧冠冠军与欧联冠军对决

**基本设置**:
- 单场决胜
- 欧冠冠军 vs 欧联冠军
- 中立场地或其中一队主场
- 90分钟平局直接点球决胜

## Phase 21-02: 篮球相关规则

本阶段添加了 10 种篮球相关规则，涵盖职业联赛、国家队赛事和特殊赛事。

### WNBA 女子篮球规则 (BasketballWnbaRules)

**特点**: 美国女子职业篮球联赛

**基本设置**:
- 每队5名球员上场
- 4节各10分钟比赛时长
- 三分线距离6.75米
- 24秒进攻时限

**赛制**:
- 常规赛36场比赛
- 季后赛采用5场3胜制
- 总决赛采用5场3胜制

**选秀规则**:
- 选秀三轮36名球员
- 乐透抽签未进季后赛球队参与
- 新秀合同4年

### NCAA 大学篮球规则 (BasketballNcaaRules)

**特点**: 美国大学体育协会篮球规则

**基本设置**:
- 每队5名球员上场
- 上下半场各20分钟比赛时长
- 三分线距离: 男子6.75米，女子6.32米
- 30秒进攻时限

**锦标赛**:
- 男子64强淘汰赛
- 女子64强淘汰赛
- 四强赛决出冠军

**业余原则**:
- 学生运动员必须是业余身份
- 允许提供体育奖学金
- 不得接受任何形式的报酬

### CBA 详细规则 (BasketballCbaDetailedRules)

**特点**: 中国男子篮球职业联赛

**基本设置**:
- 每队5名球员上场
- 4节各12分钟比赛时长
- 外援上场限制规则
- 本土球员培养规则

### FIBA 世界杯篮球规则 (BasketballFibaWorldCupRules)

**特点**: 国际篮联篮球世界杯

**基本设置**:
- 每队5名球员上场
- 4节各10分钟比赛时长
- 三分线距离6.75米
- 24秒进攻时限

**预选赛**:
- 预选赛分四个赛区
- 32支球队晋级正赛
- 小组赛+淘汰赛制

**正赛**:
- 小组赛采用循环赛制
- 16强交叉淘汰
- 四强赛决出冠军

### 奥运会篮球规则 (BasketballOlympicRules)

**特点**: 奥运会篮球比赛规则

**基本设置**:
- 每队5名球员上场
- 4节各10分钟比赛时长
- 三分线距离6.75米
- 24秒进攻时限

**参赛球队**:
- 男子12支球队参赛
- 女子12支球队参赛
- 东道主自动获得参赛资格

**赛制**:
- 小组赛分三组循环
- 每组前两名+两支最好第三名晋级
- 淘汰赛决出冠军

### NBA 全明星规则 (BasketballAllStarRules)

**特点**: NBA全明星周末篮球规则

**基本设置**:
- 全明星赛4节各12分钟
- 东部联盟 vs 西部联盟
- 球员投票选出
- 目标得分制(第4节)

### NBA 季后赛规则 (BasketballPlayoffRules)

**特点**: NBA季后赛比赛规则

**基本设置**:
- 16支球队参赛(8支/联盟)
- 7场4胜制系列赛
- 主场优势按战绩排名
- 季后赛种子排名规则

### G 联盟规则 (BasketballGLeagueRules)

**特点**: NBA发展联盟规则

**基本设置**:
- NBA球队下属发展联盟
- 球员培养和锻炼
- 单场比赛时长36分钟
- 与NBA规则略有不同

### 3x3 奥运篮球规则 (Basketball3x3OlympicRules)

**特点**: 3x3篮球奥运规则

**基本设置**:
- 3名球员上场+1替补
- 10分钟比赛或先达21分
- 12秒进攻时限
- 1分和2分得分系统

### FIBA 亚洲杯篮球规则 (BasketballFibaAsiaCupRules)

**特点**: FIBA亚洲杯篮球规则

**基本设置**:
- 16支球队参赛
- 小组赛+淘汰赛制
- 每4年举办一次
- 奥运和世界杯资格赛

## Phase 21-03: 其他球类规则

本阶段添加了 10 种其他球类运动规则，涵盖排球、网球、羽毛球、乒乓球、棒球、手球和橄榄球。

### 排球世锦赛规则 (VolleyballWorldChampionshipRules)

**特点**: FIVB排球世界锦标赛规则

**基本设置**:
- 24支队伍参赛
- 4个小组，每组6队
- 每组前4名晋级淘汰赛

**比赛赛制**:
| 阶段 | 规则 |
|------|------|
| 小组赛 | 5局3胜制 |
| 淘汰赛 | 5局3胜制 |
| 决赛 | 5局3胜制 |
| 前4局 | 25分 |
| 决胜局 | 15分 |

**淘汰赛结构**:
- 16强淘汰赛
- 8强淘汰赛
- 半决赛
- 决赛
- 三四名决赛

### 排球奥运会规则 (VolleyballOlympicRules)

**特点**: 奥运会排球比赛规则

**基本设置**:
- 12支队伍参赛
- 2个小组，每组6队
- 每组前4名晋级淘汰赛

**奖牌规则**:
| 名次 | 奖牌 |
|------|------|
| 第1名 | 金牌 |
| 第2名 | 银牌 |
| 第3名 | 铜牌 |
| 第4名 | 无奖牌 |

### 网球 ATP 总决赛规则 (TennisAtpFinalsRules)

**特点**: ATP年终总决赛规则

**基本设置**:
- 8名单打选手参赛
- 2个小组，每组4人
- 小组赛采用循环赛制

**比赛赛制**:
- 小组赛: 三盘两胜制
- 半决赛: 三盘两胜制
- 决赛: 三盘两胜制
- 每盘6-6时抢七

**积分分配**:
| 阶段 | 积分 |
|------|------|
| 小组赛每胜 | 200分 |
| 半决赛胜 | 400分 |
| 决赛胜 | 500分 |
| 全胜夺冠 | 1500分 |

### 网球戴维斯杯规则 (TennisDavisCupRules)

**特点**: 国际男子网球团体赛

**基本设置**:
- 国家队团体赛
- 单打和双打比赛
- 5场3胜制系列赛

**比赛规则**:
- 单打: 5盘3胜制
- 双打: 5盘3胜制
- 决胜盘无抢七

### 羽毛球世锦赛规则 (BadmintonBwfWorldChampionshipRules)

**特点**: BWF羽毛球世锦赛规则

**赛事类型**:
- 男单
- 女单
- 男双
- 女双
- 混双

**比赛规则**:
- 3局2胜制
- 每局21分
- 20平后需领先2分
- 最高30分封顶

### 乒乓球世界杯规则 (TableTennisWorldCupRules)

**特点**: 乒乓球世界杯规则

**基本设置**:
- 单打: 16名选手参赛
- 团体: 12支队伍参赛
- 小组赛+淘汰赛制

**比赛规则**:
- 5局3胜制(单打)
- 每局11分
- 10平后需领先2分
- 最高比分无限制

### 日本职业棒球规则 (BaseballNpbRules)

**特点**: 日本职业棒球规则

**基本设置**:
- 12支球队参赛
- 中央联盟和太平洋联盟各6队
- 每队143场常规赛

**比赛规则**:
- 9局比赛
- 3出局交换攻守
- 提前结束规则: 7局落后10分

### 世界棒球经典赛规则 (BaseballWbcRules)

**特点**: 世界棒球经典赛规则

**基本设置**:
- 20支球队参赛
- 4个小组，每组5队
- 每组前2名晋级

**赛制**:
- 小组赛循环赛
- 淘汰赛单场决胜
- 决赛在中立场地

### 手球欧冠联赛规则 (HandballEhfChampionsLeagueRules)

**特点**: 手球欧冠联赛规则

**基本设置**:
- 16支球队参赛
- 2个小组，每组8队
- 每组前6名晋级淘汰赛

**积分规则**:
| 结果 | 积分 |
|------|------|
| 胜 | 2分 |
| 平 | 1分 |
| 负 | 0分 |

**比赛规则**:
- 上下半场各30分钟
- 7名球员上场(含守门员)
- 每队最多7名替补

### 橄榄球六国赛规则 (RugbySixNationsRules)

**特点**: 欧洲六国橄榄球锦标赛

**参赛国家**:
- 英格兰
- 法国
- 爱尔兰
- 意大利
- 苏格兰
- 威尔士

**比赛规则**:
| 项目 | 规则 |
|------|------|
| 比赛时长 | 80分钟 |
| 上下半场 | 各40分钟 |
| 球员人数 | 15人制 |
| 达阵得分 | 5分 |
| 追加射门 | 2分 |
| 罚踢 | 3分 |
| 落踢 | 3分 |

**积分规则**:
| 结果 | 积分 |
|------|------|
| 胜 | 4分 |
| 平 | 2分 |
| 负 | 0分 |
| 达阵4次以上 | +1分 |
| 失利7分以内 | +1分 |
| 大满贯 | +3分 |

**特殊奖项**:
- 大满贯: 全胜夺冠
- 三冠: 胜英格兰、苏格兰、威尔士
- 木勺: 最后一名
