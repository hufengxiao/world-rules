# Phase 20: 麻将变体扩充

## Phase 20-01: 中国麻将变体

本阶段添加了 5 种中国麻将变体规则，涵盖不同地区的特色玩法。

### 湖南麻将 (HunanMahjongRules)

**特点**: 七小对盛行，玩法灵活多变

**基本设置**:
- 使用136张牌(无花牌)
- 每人起手13张
- 可以吃碰杠
- 可以点炮胡牌
- 七小对盛行

**七小对规则**:
- 七小对: 7个对子胡牌
- 七小对番数较高
- 龙七对: 有一杠的七小对
- 双龙七对: 两杠的七小对
- 湖南麻将七小对常见

**番型规则**:
| 番型 | 番数 |
|------|------|
| 平胡 | 1 |
| 对对胡 | 2 |
| 七小对 | 2 |
| 混一色 | 2 |
| 清一色 | 4 |
| 龙七对 | 4 |
| 双龙七对 | 8 |
| 十三幺 | 10 |
| 天胡 | 10 |
| 地胡 | 8 |

### 河北麻将 (HebeiMahjongRules)

- 不计复杂番型
- 强调速度和运气
- 河北麻将核心玩法

### 山西麻将 (ShanxiMahjongRules)

- 提高策略性

- 山西麻将特色

## 使用示例

```rust
use world_rules::prelude::*;

// 湖南麻将
let hunan = HunanMahjongRules::new();
println!("湖南麻将: {}", hunan.metadata().name);
println!("七小对规则: {}", hunan.seven_pairs_rules().join(", "));

// 河北麻将
let hebei = HebeiMahjongRules::new();
println!("河北麻将: {}", hebei.metadata().name);
println!("推倒胡规则: {}", hebei.tuidao_hu_rules().join(", "));

// 山西麻将
let shanxi = ShanxiMahjongRules::new();
println!("山西麻将: {}", shanxi.metadata().name);
println!("缺一门规则: {}", shanxi.quemen_rules().join(", "));

// 宁夏麻将
let ningxia = NingxiaMahjongRules::new();
println!("宁夏麻将: {}", ningxia.metadata().name);
println!("碰碰胡规则: {}", ningxia.pengpeng_hu_rules().join(", "));

// 内蒙古麻将
let inner_mongolia = InnerMongoliaMahjongRules::new();
println!("内蒙古麻将: {}", inner_mongolia.metadata().name);
println!("大胡规则: {}", inner_mongolia.dahu_rules().join(", "));
```
