# Phase 19: E2 棋类与桌游扩充

## 概述

Phase 19 扩展棋类游戏规则和桌游规则，共添加 20 种新规则。

## 19-01: 5种象棋变体规则 ✅

已完成的象棋变体：

1. **迷你象棋** - 缩小棋盘的象棋变体
2. **四国象棋** - 四人团队象棋
3. **暗棋** - 翻棋形式的象棋变体
4. **查图兰加** - 象棋的印度祖先
5. **盲棋** - 记忆象棋变体

## 19-02: 5种围棋变体规则 ✅

### 1. 围棋9路盘 (Go9x9Rules)

**特点**：
- 9×9=81个交叉点
- 适合初学者入门
- 快节奏（15-20分钟）
- 贴目：5.5目

**规则要点**：
- 标准围棋规则
- 边角战术重要性更高
- 适合练习死活和手筋

### 2. 围棋13路盘 (Go13x13Rules)

**特点**：
- 13×13=169个交叉点
- 入门到标准的过渡
- 对局时长30-45分钟
- 贴目：5.5目

**规则要点**：
- 兼顾边角和中腹战术
- 降低复杂度，保持围棋精髓
- 适合有一定基础的棋手

### 3. 盲围棋 (BlindGoRules)

**特点**：
- 使用标准19×19棋盘
- 双方不看棋盘，完全凭记忆
- 口头坐标报点落子
- 训练记忆力和推理能力

**挑战等级**：
- 普通盲棋：可询问棋盘某点状态
- 完全盲棋：禁止任何询问
- 大师级盲棋：不告知提子位置

### 4. 一色围棋 (OneColorGoRules)

**特点**：
- 双方使用相同颜色棋子
- 仅凭记忆和落子顺序区分归属
- 训练棋形识别和推理能力
- 高于盲棋的极限挑战

**规则要点**：
- 落子声明并记录
- 终局时根据记录标记双方棋子
- 专业棋手常用训练方法

### 5. 联棋 (PairGoRules)

**特点**：
- 四人参赛，分两队（黑队、白队）
- 队内两人轮流落子
- 禁止对局中交流
- 团队协作围棋

**赛事形式**：
- 世界联棋锦标赛
- 混双赛（男女搭配）
- 每队共用时间池

## 19-03: 5种其他棋类规则 ✅

### 1. 朝鲜将棋 (JanggiRules)

**特点**：
- 朝鲜半岛传统象棋
- 9×10棋盘，与中国象棋类似
- 无河流限制
- 独特的炮走法（可跳不吃）

**规则要点**：
- 将可在宫内斜走
- 兵可横向移动
- 开局可选择象马布局
- 炮可跳任意棋子移动

### 2. 泰国象棋 (MakrukRules)

**特点**：
- 泰国传统象棋，历史超过1000年
- 8×8棋盘，与国际象棋同源
- 保留古代象棋特征
- 后走法较弱（只能斜走一格）

**规则要点**：
- 无王车易位
- 无吃过路兵
- 兵升变后仍较弱
- 独特的计时计数规则

### 3. 斗兽棋 (JungleRules)

**特点**：
- 中国传统动物棋类
- 7×9棋盘
- 动物等级吃子规则
- 河流、陷阱、兽穴特殊地形

**规则要点**：
- 象最强但怕鼠
- 鼠最弱但可吃象、可下水
- 狮虎可跳河
- 陷阱降低等级
- 进入对方兽穴获胜

### 4. 播棋 (MancalaRules)

**特点**：
- 非洲古老棋类，历史超过3000年
- 两排各6个坑
- 48颗种子
- 播种和捕获机制

**规则要点**：
- 选择坑取出种子
- 逆时针播种
- 结束时对面坑2或3颗可捕获
- 连续捕获机制

### 5. 迷你将棋 (MiniShogiRules)

**特点**：
- 日本将棋简化版本
- 5×5棋盘
- 每方5枚棋子
- 保持将棋核心规则

**规则要点**：
- 持驹打入机制
- 棋子升变可选
- 将死对方王获胜
- 快节奏对弈

## 19-04: 5种桌游规则 ✅

### 1. 农场乐 (AgricolaRules)

**特点**：
- 德国经典农场桌游（2007年）
- 农场建设与家庭养育
- 14回合游戏
- 资源管理与动物饲养

**规则要点**：
- 行动格选择机制
- 房屋升级系统
- 动物圈养要求
- 家庭成员增长
- 终局得分计算

### 2. 卡卡颂 (CarcassonneRules)

**特点**：
- 德国经典板块放置桌游（2000年）
- 地图拼接与领地占领
- 84个地形板块
- 追随者派遣机制

**规则要点**：
- 板块放置规则
- 边缘必须匹配
- 道路得分规则
- 城市得分规则
- 修道院得分规则
- 农田终局计分

### 3. 皇权争夺 (DominionRules)

**特点**：
- 美国经典牌库构建桌游（2008年）
- 开创Deck Building类型
- 252种王国牌
- 每局选10种

**规则要点**：
- 行动阶段、财宝阶段、购买阶段
- 资源系统：行动点、购买点、金币
- 牌库管理机制
- 胜利点计算

### 4. 电力公司 (PowerGridRules)

**特点**：
- 德国经典经济桌游（2004年）
- 电力市场与网络建设
- 电厂拍卖机制
- 资源价格动态变化

**规则要点**：
- 电厂拍卖规则
- 资源购买（煤、石油、垃圾、核能）
- 网络建设成本
- 城市供应得分
- 回合顺序动态调整

### 5. 波多黎各 (PuertoRicoRules)

**特点**：
- 德国经典策略桌游（2002年）
- 殖民建设与资源管理
- 角色牌选择机制
- 货物生产与运输

**规则要点**：
- 角牌系统（建筑师、监工、商人、船长等）
- 作物生产规则
- 货物运输规则
- 建筑加分规则
- 胜利点计算
