## Phase 1: ValidateContext 类型安全重构

### 1.1 创建 ValidateContext 枚举
```rust
pub enum ValidateContext {
    /// 斗地主牌面 (如 "3s 4h 5d")
    DouDiZhuCards(String),
    /// 麻将牌面 (如 "1m 2m 3m")
    MahjongTiles(String),
    /// 扑克牌面 (如 "As Kh Qd")
    PokerCards(String),
    /// 象棋走法 (如 "车 0,0 0,5")
    ChessMove { piece: String, from: String, to: String },
    /// 五子棋棋盘 (坐标列表)
    GomokuBoard(Vec<(usize, usize, bool)>), // (x, y, is_black)
    /// 通用上下文
    Generic(String),
}
```

### 1.2 修改 Rule trait
```rust
pub trait Rule: Send + Sync {
    fn validate(&self, context: &ValidateContext) -> RuleResult<bool>;
    // ... 其他方法保持不变
}
```

### 1.3 更新所有游戏模块

- mahjong/rules.rs: 接收 MahjongTiles
