## 📊 数据流状态管理

### 无状态设计

World-Rules 采用无状态设计，所有规则验证基于输入上下文：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            无状态数据流模式                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    输入                  规则处理                  输出
    ┌─────────┐          ┌──────────────┐          ┌─────────┐
    │ Context │ ───────▶ │    Rule      │ ───────▶ │ Result  │
    │         │          │  (无状态)     │          │         │
    └─────────┘          └──────────────┘          └─────────┘
         │                      │                       │
         │                      │                       │
         └──────────────────────┴───────────────────────┘
                           纯函数，无副作用
```

**优势**：
1. **线程安全**: 无共享状态，自然支持并发
2. **可测试**: 输入输出确定，易于单元测试
3. **可缓存**: 结果可安全缓存，避免重复计算
4. **可组合**: 规则可自由组合，无顺序依赖
