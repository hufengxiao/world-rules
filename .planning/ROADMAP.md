# World-Rules 开发路线图 (Phase 1-60)

> **版本**: v2.0.0 → v3.0.0
> **系统**: LOOP Engineering
> **稳定性要求**: 每个 Phase 必须通过全部质量门禁才能进入下一阶段

---

## 🎯 稳定性要求（强制）

每个 Phase 必须满足以下条件才能标记为完成：

| 类别 | 要求 | 验证命令 |
|------|------|----------|
| **测试** | 所有测试通过 | `cargo test --all` |
| **代码质量** | clippy 零警告 | `cargo clippy -- -D warnings` |
| **格式** | 代码格式正确 | `cargo fmt --all -- --check` |
| **文档** | 文档编译通过 | `cargo doc --no-deps` |
| **安全** | 无已知漏洞 | `cargo audit` |
| **覆盖率** | 覆盖率 ≥ 70% | `cargo tarpaulin` |
| **性能** | 无性能回归 | `cargo bench` |
| **发布** | 版本号更新 | `cargo publish --dry-run` |
